scoring system

score = (Blocks Processed x 100) + (Time in Seconds x 2) + (Rows x Columns x 5)

part 1 : processed blocks each earn 100 points - reward progress in the game (processing as many as possible)
part 2 : time earns 2 points per second - reward stayinig alive for longer (but not too much as number would get too large)
part 3 : grid size * 5 to reward higher difficulty with larger grid size
